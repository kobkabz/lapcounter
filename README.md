# Track Lap Counter (กล้อง + Supabase)

เว็บแอปนับรอบวิ่งด้วยกล้องมือถือตั้งนิ่ง ตรวจจับการวิ่งผ่านเส้นชัยอัตโนมัติ ถ่ายภาพ + บันทึกเวลาไว้ทุกรอบ
ข้อมูลนักกีฬาและประวัติการวิ่ง sync ขึ้น Supabase ให้อัตโนมัติ

ไฟล์ทั้งหมดเป็น **static site ล้วนๆ** ไม่มีขั้นตอน build เปิด `index.html` ทดสอบตรงๆ ได้เลย

## โครงสร้างไฟล์

```
index.html            หน้าเว็บหลัก (UI, กล้อง, การ์ดต่างๆ)
app.js                ลอจิกทั้งหมด: กล้อง/ตรวจจับ, นักกีฬา, จับเวลา, sync กับ Supabase
config.js             ใส่ Supabase URL / anon key ของคุณตรงนี้
supabase-schema.sql   SQL สร้างตาราง athletes + laps บน Supabase
netlify.toml          ตั้งค่าการ deploy บน Netlify
```

## การตรวจจับ: จับความเคลื่อนไหวเร็ว (ตัวนับหลัก) + AI จดจำใบหน้า (ระบุนักกีฬาอัตโนมัติ)

- **ตัวนับรอบ** ยังคงใช้การจับความเคลื่อนไหว (motion detection) ความถี่สูง (~25 ครั้ง/วินาที) พร้อม
  hysteresis กันนับซ้ำ — เหมือนเดิม เพราะนี่คือส่วนที่ต้องเร็วและแม่นที่สุด **เส้นชัยยังจำเป็นสำหรับจับ
  "จังหวะเวลา" ที่แม่นยำ**
- **AI จดจำใบหน้าไม่ผูกกับเส้นอีกต่อไป** — เดิมระบบจะถ่ายรูป ณ จังหวะข้ามเส้นแล้วค่อยหาใบหน้าในรูปนั้น
  ซึ่งมีปัญหาว่า **หน้าคนมักไม่โผล่พอดีตรงจังหวะที่ตัวข้ามเส้น** (ก้มหน้า, หันข้าง, ยังไม่ทันหันมา) ทำให้ต้อง
  รอตรวจซ้ำเพิ่มดีเลย์ไปอีก — ตอนนี้แก้เป็น **สแกนใบหน้าทั้งเฟรมต่อเนื่องตลอดเวลา** (ไม่สนใจตำแหน่งเส้น)
  แล้วเก็บ "ความจำ" ไว้ว่าเห็นใครล่าสุดในช่วง ~4 วินาทีที่ผ่านมา พอมีคนข้ามเส้นจริง ระบบจะดึงคนที่ AI
  เพิ่งจำได้แม่นที่สุดจากความจำนี้มาใช้ทันที **ไม่ต้องรอเห็นหน้าตรงเส้นพอดี** — เห็นหน้าก่อนถึงเส้นไม่กี่
  วินาที หรือเห็นตอนเลยเส้นไปแล้วหันมา ก็ยังใช้ระบุตัวได้เหมือนกัน
- ถ้าความจำว่างเปล่า (ไม่มีใครถูกจำได้เลยในช่วงนั้น) จะลองตรวจจากรูปที่ถ่าย ณ จังหวะข้ามเส้นอีกครั้งเป็น
  ทางเลือกสุดท้าย ถ้ายังไม่เจอ ค่อยเปิดหน้าต่างให้เลือกเอง — **ไม่มีทางค้างหรือพลาดการนับ**
- ระหว่างใช้งานจะเห็นกรอบสี่เหลี่ยมล้อมหน้าคนในเฟรม พร้อมชื่อที่ AI คิดว่าใช่ (หรือ "?" ถ้ายังจำไม่ได้)
  ซ้อนทับวิดีโอตลอดเวลา ไม่ใช่แค่ตอนข้ามเส้น

### วิธีลงทะเบียนใบหน้า

1. เปิดกล้อง รอข้อความ "โหลด AI จดจำใบหน้าสำเร็จ"
2. ให้นักกีฬาคนนั้น **หันหน้าเข้ากล้องใกล้ๆ ในที่แสงสว่างพอ** แล้วพิมพ์ชื่อ กด "+ เพิ่ม" — ระบบจะพยายาม
   จับใบหน้าจากเฟรมกล้องตอนนั้นให้อัตโนมัติ (ถ้าไม่เจอหน้าชัดจะยังเพิ่มชื่อให้ปกติ แค่ยังไม่ได้จำหน้า)
3. ที่การ์ดนักกีฬาแต่ละคนจะมีป้ายบอกสถานะ **●จำหน้าแล้ว (n)** หรือ **●ยังไม่จำหน้า** — กดปุ่ม 📷 เพื่อ
   ลงทะเบียนใหม่/เพิ่มตัวอย่างได้ทุกเมื่อ (แนะนำให้ลงทะเบียนหลายมุม/หลายแสงเพื่อความแม่นยำ เก็บได้
   สูงสุด 3 ตัวอย่างล่าสุดต่อคน)
4. สไลเดอร์ **"ความเข้มงวดการจดจำใบหน้า"** — ค่ายิ่งสูงยิ่งเข้มงวด (ต้องเหมือนมากถึงจะยอมรับว่าใช่
   คนนั้น) ถ้า AIจำผิดคนบ่อยให้เพิ่มค่านี้ ถ้า AI จำไม่ได้บ่อยเกินไป (เด้งให้เลือกเองตลอด) ให้ลดค่าลง

### ⚠️ ข้อจำกัดที่สำคัญ (อ่านก่อนใช้งานจริง)

การจดจำใบหน้าสำหรับ**คนที่กำลังวิ่ง**เป็นโจทย์ที่ยากกว่าการจดจำใบหน้านิ่งๆ มาก เพราะ:

- **ภาพเบลอจากการเคลื่อนไหว (motion blur)** — วิ่งเร็วทำให้ใบหน้าเบลอในรูปที่ถ่ายได้ โดยเฉพาะกล้อง
  มือถือทั่วไปที่ไม่ได้ปรับ shutter speed สูง
- **มุมกล้อง/ระยะห่าง** — ถ้ากล้องอยู่ไกลหรือมุมเฉียง ใบหน้าจะเล็ก/ไม่ชัดพอให้ AI แยกแยะ
- **แสง** — กลางแดดจ้าเงาตกใบหน้า หรือที่มืดเกินไป ก็ลดความแม่นยำ
- **คนหน้าคล้ายกัน** (เช่นพี่น้องฝาแฝด, ทีมที่อายุใกล้กัน) อาจสับสนได้ง่ายกว่าคนทั่วไป

**คำแนะนำ:** ระบบนี้เหมาะเป็น "ตัวช่วยลดงานเลือกเอง" มากกว่า "ระบบที่แม่น 100%" — ควรมองว่าทุกครั้งที่
ขึ้นป้าย ✓จำหน้า เป็นการเดาที่น่าจะถูก แต่ควรเช็กจากรูปที่แนบในบันทึกรอบเป็นระยะๆ โดยเฉพาะการแข่งขัน
ที่ผลลัพธ์สำคัญมาก ควรใช้คู่กับคนคอยดูหน้างานหรือระบบ RFID/ชิปจับเวลาจริงสำหรับผลการแข่งขันที่เป็นทางการ

## ขั้นตอนที่ 1 — ตั้งค่า Supabase

1. สร้างโปรเจกต์ที่ [supabase.com](https://supabase.com) (ฟรี)
2. ไปที่ **SQL Editor** วางเนื้อหาทั้งหมดจาก `supabase-schema.sql` แล้วกด **Run**
   จะได้ตาราง `athletes` และ `laps` พร้อม RLS
3. ไปที่ **Project Settings > API** คัดลอก **Project URL** และ **anon public key**
4. แก้ไฟล์ `config.js`:
   ```js
   window.SUPABASE_URL = "https://xxxxxxxx.supabase.co";
   window.SUPABASE_ANON_KEY = "eyJhbGciOi...";
   ```

> ถ้ายังไม่ตั้งค่า ปล่อย `config.js` ไว้แบบเดิมได้ — แอปยังใช้งานได้ปกติ
> แต่ข้อมูลจะไม่ถูกบันทึกข้ามการรีเฟรชหน้า (เหมือนเวอร์ชันเดิมที่ไม่มีฐานข้อมูล)

## ขั้นตอนที่ 2 — ขึ้น GitHub

```bash
cd lap-counter-web
git init
git add .
git commit -m "Track Lap Counter"
git branch -M main
git remote add origin https://github.com/<username>/<repo-name>.git
git push -u origin main
```

## ขั้นตอนที่ 3 — Deploy บน Netlify

1. เข้า [app.netlify.com](https://app.netlify.com) ด้วย GitHub
2. **Add new site > Import an existing project** เลือก repo ที่ push ไป
3. **Build command:** ปล่อยว่าง, **Publish directory:** `.`
4. **Deploy site** — ได้ลิงก์ `https://xxxx.netlify.app` ทันที

หลังจากนี้ push โค้ดใหม่ขึ้น GitHub ทีไร Netlify จะ deploy ให้อัตโนมัติ

**สำคัญ:** เว็บที่ deploy แล้วจะให้ HTTPS อัตโนมัติจาก Netlify ซึ่งจำเป็นสำหรับการขอสิทธิ์กล้อง
(เบราว์เซอร์ส่วนใหญ่ไม่อนุญาตให้เปิดกล้องบนหน้าที่ไม่ใช่ HTTPS ยกเว้น localhost)

## วิธีข้อมูลถูกเก็บ

- **นักกีฬา** (`athletes`): ชื่อ/สี/ตัวอย่างใบหน้าที่ลงทะเบียนไว้ (`face_descriptors`) ต่อคน ผูกกับ
  `session_id` ที่สุ่มสร้างและเก็บไว้ใน localStorage ของเบราว์เซอร์เครื่องนั้น
  (คนละเครื่อง/เบราว์เซอร์ = คนละชุดข้อมูล)
- **รอบที่นับได้** (`laps`): ทุกครั้งที่นับรอบ (ทั้งอัตโนมัติและกดเอง) จะถูกส่งขึ้น Supabase ทันที
  พร้อมเวลาแข่ง เวลานาฬิกา และรูปถ่าย (เก็บเป็น base64 ในคอลัมน์ `photo`)
- กด **รีเซ็ตทั้งหมด** จะลบแถวใน `laps` ของเซสชันนั้นบน Supabase ด้วย (นักกีฬาที่เพิ่มไว้จะไม่หาย)
- ถ้า Supabase เชื่อมต่อไม่ได้ชั่วคราว แอปจะยังทำงานต่อได้ในเครื่องนั้น
  (ข้อมูลรอบที่บันทึกไม่สำเร็จจะมี toast แจ้งเตือน)

## ความปลอดภัยของข้อมูล (สำคัญ)

แอปนี้ไม่มีระบบล็อกอิน ใช้ `session_id` แบบสุ่มแยกข้อมูลแต่ละเครื่อง เหมาะกับใช้งานส่วนตัว/ทีมเล็ก
ถ้าต้องการให้โค้ชหลายคนแชร์ข้อมูลเดียวกัน หรือมีระบบบัญชีผู้ใช้จริง แนะนำเพิ่ม
[Supabase Auth](https://supabase.com/docs/guides/auth) แล้วปรับ policy ให้อิงจาก `auth.uid()`

ถ้าต้องการเก็บรูปจำนวนมากในระยะยาว แนะนำย้ายไปใช้ **Supabase Storage** แทนการเก็บ base64
ในตาราง (ตอนนี้เก็บใน DB โดยตรงเพื่อความง่าย เหมาะกับการใช้งานทั่วไป)

## ฟีเจอร์หลัก

- ตั้งกล้องมือถือนิ่ง ปรับตำแหน่งเส้นชัย/ความไว/ระยะกันนับซ้ำ/ความเข้มงวดการจดจำใบหน้าได้
- ตัวนับรอบหลักใช้การจับความเคลื่อนไหวความถี่สูง พร้อม hysteresis กันนับซ้ำ
- **AI จดจำใบหน้า**: ลงทะเบียนหน้านักกีฬาไว้ล่วงหน้า แล้วระบบจะพยายามระบุอัตโนมัติว่าใครวิ่งผ่าน
  เมื่อมีนักกีฬามากกว่า 1 คน — จำไม่ได้ก็เด้งให้เลือกเองเหมือนเดิม ไม่มีทางค้าง (ดูข้อจำกัดด้านบน)
- ปุ่ม +1 กดเองสำรองไว้ทุกคน
- **สถิติรายบุคคล**: ตารางสรุปจำนวนรอบ, เวลาต่อรอบที่เร็วที่สุด, เวลาต่อรอบเฉลี่ย ของนักกีฬาแต่ละคน
  (คำนวณจากรอบทั้งหมดที่บันทึกไว้ของนักกีฬาคนนั้น)
- **ประวัติการวิ่งตามวันที่**: จัดกลุ่มทุกรอบที่นับได้ตามวันที่ (ใช้เวลานาฬิกาจริงตอนวิ่งผ่าน) แสดงเป็น
  ตาราง แตะที่หัวข้อวันที่เพื่อย่อ/ขยายแต่ละวันได้
- ส่งออกบันทึกทั้งหมดเป็น CSV
- ข้อมูลนักกีฬา + ใบหน้าที่ลงทะเบียน + ประวัติการวิ่ง sync ขึ้น Supabase อัตโนมัติ

**หมายเหตุเกี่ยวกับปุ่ม "รีเซ็ตทั้งหมด":** ปุ่มนี้จะลบรอบที่นับไว้ทั้งหมดออกจาก Supabase จริงๆ
(ทั้งของวันนี้และวันก่อนหน้า) เพราะฉะนั้นถ้าต้องการเก็บสถิติ/ประวัติของหลายๆ วันไว้เปรียบเทียบกัน
**ไม่ควรกดรีเซ็ตระหว่างวัน** — ให้กด "เริ่มต่อ"/"หยุดชั่วคราว" ไปเรื่อยๆ ในแต่ละวันแทน แล้วค่อยรีเซ็ต
เมื่อต้องการเริ่มเก็บสถิติชุดใหม่จริงๆ เท่านั้น
